Run the local server and open `/arenas.html` to see the animated arena archive. The four maps cycle by curriculum sector and preserve existing game progress.

New players see the eight-scene animated introduction automatically. Existing players can select **Replay intro** below the world or click the game logo. Continue/Back, arrow keys, pause, reduced motion, and Skip/Escape control playback without changing progress.

See the [project README](../README.md) for local setup, controls, and current scope.
