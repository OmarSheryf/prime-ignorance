Run the local server and open `/arenas.html` to see the animated arena archive. The four maps cycle by curriculum sector and preserve existing game progress.

The title menu offers **Enter the machine** for new players and **Resume the signal** for returning players. New expeditions start with the eight-scene introduction. **The world before** and **Replay intro** replay it; the game logo returns to the menu. Continue/Back, arrow keys, pause, reduced motion, and Skip/Escape control playback without changing progress.

See the [project README](../README.md) for local setup, controls, and current scope.
